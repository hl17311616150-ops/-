## 5. 防错措施（视觉组件，已固化为长期偏好）

根因教训：Plan 4 写计划时没把 mockup 视觉参数锁全，fresh implementer 看不到 mockup 只能默认发挥、reviewer 无视觉基准，导致卡片栈/按钮连续返工。

后续每个 Plan 必须：
1. 视觉组件把 mockup 的**尺寸 / 对齐 / 位置 / 间距**精确值或 mockup 路径写进 brief；
2. 派 implementer 时给对应 mockup 文件路径作视觉参考；
3. reviewer 也拿 mockup 对照；
4. 关键视觉值写进测试断言（jsdom 用 inline style 断言）；
5. 每个 Plan 收尾做「渲染对照 mockup」浏览器走查。
