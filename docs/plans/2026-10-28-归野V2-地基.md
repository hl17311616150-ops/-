# 归野 V2 · 地基（Plan 1）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 V1.19 工程上建立 V2 的数据模型 v2、照片统一到 IndexedDB、react-router 封面放射式导航骨架，为后续 Plan 2–6 提供可运行的基础。

**Architecture:** 壳层重写（strangler）——保留 V1.19 的工程配置、storage、album、destinations、community、footprint 等已验证资产；新增 v2 时间/行程类型与草稿存储，bump schema 到 v2，废弃 footprint 里走 localStorage 的旧照片路径；用 react-router 替换 AppShell 的页面切换，先放占位页面，后续 Plan 逐个填充。

**Tech Stack:** React 19 + Vite 8 + TypeScript 6（strict）+ Tailwind CSS v4 + react-router-dom 7 + vitest 5 + oxlint；IndexedDB（album，fake-indexeddb 测试）。

**Spec:** `docs/specs/2026-10-28-归野V2-design.md`（项目根另有 `归野V2-设计文档.md`）。

## Global Constraints

- 不新增运行时依赖（react-router-dom 7、lucide-react 已在 package.json）；不引入 UI 框架/状态管理库。
- 类型严格：`tsc -b` 必须零错误；新字段在旧数据上缺失时一律容错（optional + 守卫），不白屏。
- 存储：配置/业务状态走 localStorage（命名空间 `travel:v1:`，经 `storage/store.ts`）；照片走 IndexedDB（`lib/album.ts`）。
- 布局容器：`max-width:480px; margin:0 auto`（不写死 390px）。
- 测试：纯逻辑用 vitest；每个新函数/组件有对应测试；`npm run test`、`npm run lint`、`npm run build` 必须全绿。
- 文案：品牌"归野"；slogan"归山野，见自己"；本 Plan 不写最终 UI 文案细节（占位即可）。
- Git：可执行文件完整路径 `D:\软件\Git\cmd\git.exe`；提交信息用 `feat:/chore:/refactor:` 前缀。

## Review Focus

1. **跨月/跨年日期**：出发 12-31、返程 01-02 时，`computeTripTime` 的 dates 必须正确进入下一年（`addDays`/`dayDiff` 不能在月末出错）。→ 测试加在 Task 2。
2. **返程早于出发**：`computeTripTime` 收到 diff<0 时，不得产生负数晚数/完整日，也不生成倒退日期（容错为一日游或抛明确错误，由实现选定并固定）。→ 测试加在 Task 2。
3. **损坏的草稿数据**：`travel:v1:planning-draft` 被改成字符串/缺 step 字段时，`getDraft()` 必须回退 null，不抛错。→ 测试加在 Task 4。
4. **IndexedDB 不可用/迁移失败**：启动时照片迁移若抛错，必须被捕获、不阻塞应用启动。→ 测试加在 Task 5。
5. **照片迁移幂等**：`migrateLegacyPhotos` 第二次运行（旧 key 已删）返回 0，不产生重复照片。→ 测试加在 Task 5。

  - `interface TripTimeSummary { totalDays: number; nights: number; fullDays: number; dates: string[] }`

- [ ] **Step 1: 写失败测试**

```typescript
import { addDays, computeTripTime, dayDiff } from './time'

describe('time', () => {
  it('dayDiff 计算两个日期相差天数', () => {
    expect(dayDiff('2026-11-08', '2026-11-13')).toBe(5)
  })
  it('addDays 正确顺延（含跨月跨年）', () => {
    expect(addDays('2026-11-08', 5)).toBe('2026-11-13')
    expect(addDays('2026-12-31', 2)).toBe('2027-01-02') // Review Focus #1
  })
  it('computeTripTime 8号上午出发、13号晚上返程 = 6天5晚、4完整日', () => {
    const s = computeTripTime({ date: '2026-11-08', period: 'morning' }, { date: '2026-11-13', period: 'evening' })
    expect(s.totalDays).toBe(6)
    expect(s.nights).toBe(5)
    expect(s.fullDays).toBe(4)
    expect(s.dates).toEqual(['2026-11-08','2026-11-09','2026-11-10','2026-11-11','2026-11-12','2026-11-13'])
  })
  it('同日出发返程 = 一日游（1天0晚0完整日）', () => {
    const s = computeTripTime({ date: '2026-11-08', period: 'morning' }, { date: '2026-11-08', period: 'evening' })
    expect(s).toMatchObject({ totalDays: 1, nights: 0, fullDays: 0 })
  })
  it('返程早于出发时不产生负数（Review Focus #2）', () => {
    const s = computeTripTime({ date: '2026-11-13', period: 'morning' }, { date: '2026-11-08', period: 'evening' })
    expect(s.nights).toBeGreaterThanOrEqual(0)
    expect(s.fullDays).toBeGreaterThanOrEqual(0)
  })
})
```
