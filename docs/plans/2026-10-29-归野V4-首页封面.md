## Review Focus

1. **误判"已生成"**：`getTrip()` 无行程时会自动创建默认行程（source='self'）；首页若调用它会把"全新"误判为"已生成"。→ 必须用 `loadObject` 只读、且校验 `source==='ai' && dayPlans.length>0`。测试：清空存储后为 fresh（Task 3）。
2. **草稿 step 映射**：time/route/points 各有中文标签，step='result' 不算草稿（已生成）。测试：各 step 的 hint 文案、result 落到 generated（Task 3）。
3. **诗句确定性**：同一天固定、零点后换；不能每次渲染随机。测试：同一日期两次渲染一致、相邻日期可不同（Task 1 + Task 4）。
4. **卡片栈切换与倒梯形**：在卡片栈位置上下滑动（桌面滚轮）切换最前卡片、循环；最前卡片进详情、后面卡片点击切换。c1 100%/top0、c2 96%/top10（左右各缩进2%）、c3 92%/top20（左右各缩进4%），居中对称、缩略图 62→59→56。测试：切换方向/循环/点击 + 布局（Task 6）。
5. **按钮位置不动**：按钮上方用固定高度状态槽承载 hint，hint 有无 / 文案长短都不改变按钮 Y。测试：三状态按钮相对顶部锚点一致（Task 7）。

```ts
import { VERSES } from '../data/verses'
import type { Verse } from '../data/verses'

function hashString(s: string): number {
  let h = 0
  for (let i = 0; i < s.length; i += 1) h = (h * 31 + s.charCodeAt(i)) >>> 0
  return h
}

export function verseForDate(date: Date): Verse {
  const key = `${date.getFullYear()}-${date.getMonth() + 1}-${date.getDate()}`
  return VERSES[hashString(key) % VERSES.length]
}
```

```ts
import { getDraft } from './planningDraft'
import { loadObject } from '../storage/store'
import { K } from '../storage/keys'
import type { PlanningStep, Trip } from '../types'

export type HomeState =
  | { kind: 'fresh' }
  | { kind: 'draft'; stepLabel: string; hint: string }
  | { kind: 'generated'; title: string; tripId: string; hint: string }

const STEP_LABEL: Partial<Record<PlanningStep, string>> = {
  time: '选时间',
  route: '确认路线',
  points: '选景点',
}

export function getHomeState(): HomeState {
  const draft = getDraft()
  if (draft && draft.step !== 'result') {
    const stepLabel = STEP_LABEL[draft.step] ?? '选景点'
    return { kind: 'draft', stepLabel, hint: `上次规划到“${stepLabel}”，还差一步` }
  }

  const trip = loadObject<Trip>(K.trip, () => true)
  if (trip && trip.source === 'ai' && Array.isArray(trip.dayPlans) && trip.dayPlans.length > 0) {
    return { kind: 'generated', title: trip.title, tripId: trip.id, hint: `你有一份“${trip.title}”` }
  }

  return { kind: 'fresh' }
}
```
