# 归野 V5 · 行程回顾 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `/trip/:id` 占位页替换为真实行程回顾：顶部返回与行程标题、「日记 / 照片」双 Tab（日记图文混排、照片聚合网格）、点照片进全屏并按"照片按张翻、文字按日记条目切换"联动。

**Architecture:** 核心联动由纯函数 `buildPhotoStream` 把日记条目展开成"照片→所属条目"的扁平序列，两 Tab 与全屏共用同一序列、照片在 IndexedDB 只存一份。阶段 0 无真实日记，内置离线种子（本地图片 + 演示条目）幂等播种，不写回 `K.trip`。展示层拆为职责单一组件，TripDetail 负责加载与组装。全程本地、不联网。

**Tech Stack:** React 19 + Vite 8 + TypeScript strict + Tailwind v4 + react-router 7 + vitest（jsdom + fake-indexeddb）；不新增依赖。

**Spec:** `docs/specs/2026-10-28-归野V2-design.md` §6.3 行程回顾、§6.6 导航、§5 IA。

## Global Constraints

- React 19 + Vite 8 + TS strict（noUnusedLocals + verbatimModuleSyntax）+ Tailwind v4 + react-router 7；**不新增依赖**。
- 布局：`max-width:480px` 居中；页面 `h-[100svh]`；**无底部 Tab**（封面放射式），页内 Tab 仅用于回顾视图切换。
- 所有可见图标 36px、触控热区 44px；功能页顶部返回（沿用 PlanFlow header 模式）。
- 照片**只在 IndexedDB 存一份**；日记与照片 Tab 是同一数据的不同视图，不重复存储；**纯文字日记不进全屏照片流**。
- 本 Plan 为**只读回顾**：不含日记的新增 / 编辑 / 删除（YAGNI，编辑能力属 V1 弹层，本页不接线）。
- 种子数据与图片全部离线内置（复用 `src/assets/home/*.jpg`），不依赖运行时网络。
- 关键视觉值用 inline style 书写以便 jsdom 断言（沿用 Plan 4 防错惯例）；结构性布局用 Tailwind class。
- 质量门：`npm run test`、`npx tsc -b`、`npm run lint`、`npm run build` 全绿。

## Review Focus

1. **空数据不白屏**：`K.trip` 的 diary 为空、且种子未播时，两个 Tab 都要渲染空状态而非报错；照片 Tab 计数为 0、网格为空。测试：空 entries 下 DiaryTab/PhotoGridTab 渲染（Task 4、5、7）。
2. **纯文字条目**：不进照片流（`buildPhotoStream` 跳过 photoIds 为空的条目），但日记 Tab 正常显示；全屏序列中不存在无照片项。测试：stream 长度排除纯文字、DiaryTab 仍包含该条目（Task 1、4）。
3. **同条多图文字不切换**：stream 中同一条目的多个 item 必须共享同一个 entry 引用；全屏在这几张间翻页时地点 / 文字 / 时间不变，仅计数递增，跨到下一条目才更新。测试：相邻 item 的 entry 引用相等、viewer 翻页断言（Task 1、6）。
4. **种子幂等且不污染主行程**：重复调用 `ensureSeedPhotos` 不产生重复记录；`getReviewData` 不得写回 `K.trip`（其 diary 保持原值）。测试：两次播种后 album 长度恒定、`K.trip` 未被改写（Task 3）。
5. **全屏翻页边界**：第一张向左、最后一张向右不得越界（按钮禁用 + index clamp）；关闭触发 onClose。测试：viewer 边界与关闭（Task 6）。
