# 主页摘要化（推荐页 / 空间页）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task. Steps use checkbox syntax.

**Goal:** 把推荐页、空间页从长滚列表改成「一屏摘要 + 点进上拉 tall 面板看全部」，使三个主页全部定死一屏、上下滑永远切页。

**Architecture:** 复用现有 `BottomSheet`（`height="tall"`），主页只渲染摘要与「查看全部」入口，完整列表/操作移进 tall 面板；面板内再叠详情（沿用现有 zIndex 层级）。不改切页手势与路由。

**Tech Stack:** React + Vite + TS + Tailwind v4 + localStorage（现状）。

**Spec:** `docs/specs/2026-10-26-主页摘要化-design.md`（用户已批准，已确认两个决策：推荐主页不放筛选、空间主页为纯概览卡）。

## Global Constraints
- 复用 `BottomSheet`，不新建面板形态；tall = `max-h-[88svh]`。
- 主页必须定死一屏、不可滚；滚动条只存在于 tall 面板正文框内。
- 数据源：`Destinations`、`recommendByMonth`、`getPhotos/getVisited`、`useTheme`、`addWaypoint/setDestination`、`SeasonBadge`、`EmptyHint`。
- 面板内再叠详情时，下层面板 zIndex 60、详情半屏 50 或按需，确认框 70。
- 意图筛选/搜索只在推荐二级面板内；主页不放。
- 8pt 栅格 / Design Tokens / 手机式细滚动条（已全局）。

## Review Focus
1. **主页溢出**：摘要改动后，推荐/空间主页在 390×844 与窄屏下必须 `scrollHeight==clientHeight` 不可滚。
2. **二级锁定切页**：tall 面板打开时不能滑动切到其他主页；关闭后恢复。
3. **面板内滚动**：36 个目的地、完整照片墙在 tall 面板内可滚，滚动条在框内。
4. **详情再叠**：推荐面板内点卡片 → 半屏详情 → 加入路线，多层面板 body 锁不提前释放。
5. **空态**：空间空数据（无足迹无照片）仍显示引导，不因摘要化丢失。
