# 归野 V7 · 社区（发布流程 + 评论区）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Plan 6 深色社区体系上补齐「发布流程」（行程结束整理并发布 + 途中边走边发）与「评论区」（嵌套回复、最热/最新、即写即发），全部只读本地模拟、数据持久化在 localStorage。

**Architecture:** 先删除封闭的旧 v1 社区孤岛（38 文件，经依赖可达性验证无任何活跃文件引用），再在新体系内新建用户帖数据层（`StoredPost extends CommunityPost`，自包含 entries，落 `K.communityOngoing/communityCompleted`）与评论数据层（种子假评论 + 用户评论落 `K.communityComments`）。发布页与评论页为独立深色页面，新增两条路由；列表/详情的数据源由只读 `COMMUNITY_POSTS` 切换为合并后的 `getAllPosts()`，评论项与发布按钮接线，行程回顾页日记条目经可选回调接「边走边发」。

**Tech Stack:** React 19、Vite 8、TS 6 strict、Tailwind v4、react-router-dom 7、vitest 5（jsdom + fake-indexeddb）、oxlint。

**Spec:** `docs/specs/2026-10-28-归野V2-design.md` §6.4.3 发布流程（260–264 行）、§6.4.4 评论区（266–269 行）、§6.4.2 游记详情（252–258 行）。

## Global Constraints

- 不新增依赖；只读 + 本地模拟，不接真实后端/大模型/联网/相机；不做真实分享。
- 页面最大宽 480px，整体深色背景 `#1c2621`；衬线栈 `"Noto Serif SC","Songti SC",serif`；主绿 `#6FA879`、浅绿 `#9cc79e`。
- 关键视觉值用 inline style 便于 jsdom 断言（jsdom 无布局），结构性布局用 Tailwind；视觉精确值逐字来自 mockup，写进 brief 与测试断言。
- 复用现有类型：`CommunityPost`/`CommunityAuthor`（`src/data/community.ts`）、`DiaryEntry`（`src/types.ts`）、`Difficulty`（`src/data/hotRoutes.ts`）；不改写已封板的 `PhotoGridTab`/`FullscreenViewer` 逻辑，仅只读复用。
- 用户帖、用户评论持久化到 localStorage（经 `store.ts` 的 `travel:v1:` 命名空间，损坏/形状错误一律回退不抛错）；所有「点赞」（帖子/评论）沿用 Plan 6 本地视觉态，不持久化。
- 一个 trip 至多对应一个用户帖（确定性 id，重复发布覆盖），不建多帖映射；不引入额外抽象层。
- 每个 Task 结束提交；commit message 用 `feat:`/`test:`/`chore:` 前缀；不执行 merge/push（留待用户单独授权）。

## Review Focus

1. **损坏/形状错误的本地数据**：localStorage 中用户帖/评论被写成对象、标量或混入坏条目时，加载必须回退/过滤，不白屏、不抛未捕获异常 —— Task 2、Task 3 测试。
2. **空白与非法输入**：发布时标题空白有兜底、评论空白或纯空格不写入、重复点发送不产生重复评论 —— Task 3、Task 4、Task 5 测试。
3. **嵌套回复完整性**：父评论排序变化时其回复始终挂在同一父下，回复按时间正序，「查看全部 N 条回复」可展开/收起，不串帖 —— Task 3、Task 5 测试。
4. **发布后数据一致**：发布/收尾后该 trip 的旧 ongoing 被移除、信息流与详情能看到新帖且不重复，刷新后仍在（持久化）—— Task 2、Task 6 测试。
5. **未知/直达路由**：直接访问不存在帖子的评论页或发布页初始化失败时，有兜底与返回入口，不白屏 —— Task 5、Task 6 测试。
