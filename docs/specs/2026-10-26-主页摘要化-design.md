# 主页摘要化（推荐页 / 空间页）设计

> 2026-10-26 · 归野旅游 App · v1.12 方向

## 意图与 Why

用户发现一个真实交互冲突：三个主页之间用**上下滑动切页**，但**推荐页（6549px，36 个目的地）和空间页（895px）是长滚列表**——同一个手势既管"翻页"又管"滚列表"，越长越别扭（"从推荐页划到下一页要划很久"）。

已确认方向：**推荐页、空间页都改成「一屏摘要 + 点进二级看全部」**，使三个主页全部定死一屏，上下滑永远是切页，不再和滚动打架。

## 目标 / 非目标 / 反目标

**目标**
- 推荐页一屏：当前月份前 3–4 个推荐目的地（紧凑卡片）+「查看全部目的地」入口。
- 空间页一屏：个人数据概览卡（足迹数 / 照片数 / 当前主题）+「查看全部」入口。
- 二级页形态 = **上拉 tall 覆盖层**（与"更改路线"面板一致），滚动条锁在面板框内。
- 三个主页定死一屏；上下滑始终切页。

**非目标**
- 不新增第三种页面形态（不做独立整页二级页）。
- 不改切页手势与右侧导航。
- 不做真实地图 / 第三方数据库等 v2 项。

**反目标**
- 主页不出现超过一屏的滚动。
- 面板打开时不能切页（维持现有层级锁定）。
- 不做成"又一个长滚页"。

## 约束

- 复用现有 `BottomSheet`（`height="tall"` = 88svh），不新建形态。
- 现有数据：`Destinations`（36 个）、`recommendByMonth`、`getPhotos` / `getVisited`、`useTheme`。
- 滚动条 = v1.11.1 全局细滚动条，锁在面板框内。
- 遵循 8pt 栅格 / Design Tokens / 手机式布局。

## 方案（用户已选定：上拉面板）

### 推荐页主页一屏
- 标题「本月去哪儿」+ 副标题（月份）。
- 显示 `recommendByMonth(Destinations, month)` 的**前 3 个**（无意图过滤时）。
- 每张紧凑卡片：名字 / 地点 / 一行简介（line-clamp-2）/ 类型标签。
- 底部入口按钮「查看全部目的地（N 个）」→ 打开 tall 面板。
- **意图筛选和搜索移入二级面板**，主页摘要不放筛选（保持一屏、干净）。

### 推荐页二级（上拉 tall 面板）
- 完整列表（36 个全量，按当前月推荐排序）。
- 保留意图筛选 chips + 新增搜索框（按 name/location/typeTags）。
- 复用现有详情半屏逻辑（点卡片 → 半屏详情 → 加入路线），面板内再叠详情。

### 空间页主页一屏
- 一个概览卡：当前主题名、足迹数量、照片数量，三项各一行小结。
- 底部入口「查看全部」→ 打开 tall 面板。
- 空态时：仍是"去找个目的地"引导。

### 空间页二级（上拉 tall 面板）
- 完整「主题切换 / 足迹路线 / 照片墙」三块，滚动条在面板框内。
- 主题切换、标记去过、加照片/删照片的交互原样搬进面板。

## 涉及文件

- `src/pages/Recommend.tsx` —— 重构为主页摘要 + 二级 tall 面板。
- `src/pages/Space.tsx` —— 重构为主页概览卡 + 二级 tall 面板。
- 若面板内容变多，可拆子组件；优先复用现有 `BottomSheet` / `DestinationPickerSheet` 模式。
- `e2e/app.spec.ts` —— 更新/新增验收（主页不滚、面板内滚动、二级锁定切页）。

## 留给实现者的决定

- 摘要卡布局（竖排 vs 横向滚动）——推荐竖排紧凑卡（手机纵向、一屏放下 3 个）。
- 二级面板是否需要 footer —— 不需要固定 footer，用面板自身滚动。
- 搜索框防抖 —— 纯前端小列表，无需防抖。
